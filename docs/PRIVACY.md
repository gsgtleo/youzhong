# 隐私说明

本项目的设计前提是**数据留在你自己的服务器上**。以下说明适用于网页端（PWA）、安卓客户端与桌面客户端。

## 1. 我们收集什么

| 数据 | 存放位置 | 用途 |
| --- | --- | --- |
| 账号、密码哈希 | 你部署的服务端 SQLite | 登录鉴权（密码用 scrypt 加盐哈希，不可逆） |
| 清单、任务、日程、标签、设置 | 你部署的服务端 SQLite | 核心功能 |
| 会话令牌 | 浏览器 Cookie / 客户端本地存储 | 保持登录 |
| 离线快照与待同步队列 | 浏览器 IndexedDB | 断网可用 |
| 服务端地址 | 浏览器 localStorage / 桌面端 `config.json` | 连接你的服务器 |
| WebDAV 地址与账号密码 | **仅浏览器 localStorage**，不上传服务端 | 备份到你自己选择的 WebDAV |
| 通知渠道 Webhook 与密钥 | 服务端 SQLite，密钥经 AES-256-GCM 加密 | 推送到你自己配置的钉钉/飞书群 |

## 2. 我们不上传什么

- 没有统计、埋点、崩溃上报，不向任何第三方服务器发送数据
- 不含广告 SDK、不含社交登录
- 唯一的对外网络请求是：你配置的通知渠道 Webhook，以及你主动触发的 WebDAV 备份

## 3. 数据控制

- **导出**：设置 → 数据与缓存 → 导出到本地（JSON）
- **备份**：可直接复制 SQLite 文件，或使用内置 WebDAV 备份
- **删除**：删除任务/清单即时生效；删除账号需管理员在成员管理中操作；彻底清除可删除服务端数据库文件

## 4. 客户端权限（安卓）

| 权限 | 用途 |
| --- | --- |
| 网络 / 网络状态 | 连接你填写的服务器 |
| 通知、精确闹钟、前台服务、开机自启 | 到点提醒 |
| 忽略电池优化 | 保证后台长连接存活（可选，由你手动开启） |
| 读取/写入日历 | 仅在你开启「同步到系统日历」时使用，只增删本项目创建的条目 |

## 5. 安全建议

- 公网部署请务必使用 HTTPS 反向代理，并设置足够强的 `APP_SECRET` 与管理员密码
- WebDAV 凭据保存在浏览器本地，公用设备上请勿保存，用完可在设置中清除
